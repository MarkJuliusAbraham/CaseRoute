Write path

On: the generator calls POST /api/cases, which stores each submission in Kafka and replies 202; a consumer saves it to PostgreSQL in batches. Off: it calls POST /api/cases/direct, which saves to PostgreSQL before replying 201. Applies to the next run, so runs can be compared.
